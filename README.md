# CS3C Website

Official website of the CS3C platform.

## Technology

- Astro
- Tailwind CSS v4

## Current Status

✅ Foundation completed

The engineering foundation of the website has been completed.

Implemented:

- reusable design system
- reusable layouts
- responsive page shell
- metadata support
- production build

The next milestone is the implementation of the production homepage.

## Development

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Create production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
