# ADR-0002

Title:
Adopt the five-layer CS3C Brand Mark

Status:
Accepted

Context

The project required a visual identity that represents the CS3C Knowledge System
rather than generic cybersecurity imagery.

Decision

Adopt a five-layer left-aligned mark representing:

Research
Methodology
Models
Workbench
Publications

Consequences

- single master geometry
- SVG-first assets
- scalable visual identity
- independent symbol and wordmark
- reusable across documentation, software and publications
