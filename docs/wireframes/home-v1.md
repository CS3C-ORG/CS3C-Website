# Home Page Wireframe — v1

**Status:** Draft

## Goal

The home page should immediately communicate that **CS3C is a practical cybersecurity research and engineering platform**.

Visitors should naturally discover projects, publications and tools before learning about the organization itself.

---

# Primary Navigation

- Research
- Projects
- Publications
- About

Primary CTA:

**Explore Projects**

Secondary CTA:

**Explore Research**

---

# 1. Header

```
+------------------------------------------------------------------+
| CS3C            Research  Projects  Publications  About          |
+------------------------------------------------------------------+
```

### Requirements

- Simple wordmark
- Minimal navigation
- No marketing banner
- No "Request a Quote"
- Mobile-friendly navigation

# Visual Direction

- Large typography
- Generous whitespace
- Strong visual hierarchy
- Minimal color palette
- Professional appearance
- No stock photos
- No shields
- No hackers in hoodies
- No unnecessary animations
- Fast loading
- Mobile-first
- Accessibility by design
